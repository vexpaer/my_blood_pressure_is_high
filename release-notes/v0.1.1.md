# 我有高血压 v0.1.1

> 少盐 · 早睡 · 动一动。Polish Release：**Paper Minimal 2.0**。

在 v0.1.0 "功能成立" 的基础上，这一版的目标是 **让人愿意每天打开**：
数据可视化、微动画、图形化反馈，以及真正接通的高德地图。

## 新增

- **早睡早起 → Sleep Arc**：半圆夜间时间轴成为页面视觉中心——
  左端入睡、右端起床、中央大数字，首次进入时从 0 描画到 100%。
- **少吃点盐 → 真实地图**：通过 GitHub Secret 注入高德 Key 后，
  地图、附近餐厅与低盐友好度 Marker 全部接通；
  详情页新增 Score Ring 圆环分数与「为什么是这个分」的可解释评分。
- **抬腿跑跑 → Streak Ring + 动画**：柿子橙连续天数圆环、
  最近 7 天柱条生长动画、保存成功时的描画反馈与轻触觉。
- **设置 → 数据导出**：一键把睡眠与运动记录打包成 ZIP
  （sleep.csv / exercise.csv / settings.json / README.txt）保存到手机任意位置。
- **统一设计系统**：Motion tokens（尊重系统"移除动画"）、
  Visualization tokens、28 个统一线性图标、底部导航滑动药丸动效。

## 修复

- CI / Release 构建此前未注入 `AMAP_API_KEY`（本版起自动注入）
- 高德 SDK 隐私合规初始化（同意隐私说明后才初始化地图/搜索）
- 定位权限拒绝流程与相关无障碍问题

## 安装

下载下方 `my-blood-pressure-is-high-0.1.1.apk`（Android 8.0+，arm64）。
本 Release 构建内置高德 Key（与发布签名绑定），安装即可使用真实地图。

## 隐私

所有数据只存在这台手机上；导出是你主动触发的唯一"数据出口"。
定位仅在使用「少吃点盐」时访问一次。
