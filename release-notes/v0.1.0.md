# 我有高血压 v0.1.0

> 少盐 · 早睡 · 动一动。首个公开版本。

## 这是什么

一个温和、自嘲、不制造焦虑的 Android 生活方式 App。
不是医疗诊断 App —— 名字只是提醒你少盐，别慌，先把觉睡好。

## v0.1.0 包含

- **早睡早起**
  根据手机使用情况估算昨晚睡了多久（附「根据手机使用情况估算，不是医疗监测」标注）。
  最近 7 天、平均睡眠、入睡/起床趋势；可手动修正，修正数据标记「手动修改」。
- **少吃点盐**
  查看附近餐厅与低盐友好度（0–10，本地可解释评分），每家店都给
  「来了可以点 / 尽量少碰」的点餐指引。
  本 Release 未内置高德 Key，地图页为演示模式；按 README 配置 `AMAP_API_KEY`
  重新构建即可启用真实地图。
- **抬腿跑跑**
  简单记录运动：次数 / 组×次 / 时间 / 距离 / 重量+组×次，连续天数。
- **设置**
  自定义底部导航名称与主题（跟随系统 / 浅色 / 深色）。

## 安装

下载下方 `my-blood-pressure-is-high-0.1.0.apk`，安装时允许
「安装未知来源应用」即可。需要 Android 8.0+（arm64）。

## 隐私

所有数据只存在这台手机上。无账号、无上传、无统计、无广告。
「少吃点盐」只在使用时访问一次定位。
